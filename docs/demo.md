# 演示路径

启动 API 与前端后，按以下顺序演示。问题可直接复制到问答框。

## 1. 数据看板

- 顶部指标：情报记录、向量块、AI 漏洞、RSS 源；
- 类别占比：点击任一攻击类型，下钻到漏洞清单；
- 应急决策 TOP 3：按 KEV 在野 / CVSS / EPSS 排序。

## 2. 情报监测

- 运行记录：每次全链路的状态、耗时、新增条数；
- 每日简报：`data/daily/YYYY-MM-DD.md`。

## 3. 智能问答

| # | 问题 | 观察点 |
|---|---|---|
| 1 | `CVE-2026-59822 是什么漏洞？` | 点查路由、漏洞卡片、CWE 映射、NVD 链接 |
| 2 | `它的攻击链呢？` | 多轮实体继承，不重复编号 |
| 3 | `和同类漏洞比它怎么样？` | 同组件/同攻击类型关联推理 |
| 4 | `CVE-2026-37004 影响了哪些版本？该怎么修复？` | 版本区间 + 修复建议 + CPE |
| 5 | `有哪些文章分析过 LiteLLM？` | 组件点查 + 缝合表反查 |
| 6 | `Open WebUI 呢？` | 模糊指代承接上一轮组件 |
| 7 | `2026 年 9 月披露的 CVSS 9 分以上的 AI 漏洞有哪些？` | 条件筛选 SQL |
| 8 | `最近有哪些 RCE 的 AI 漏洞？` | 时间窗真实日期过滤 |
| 9 | `CVE-2026-99999 是什么漏洞？` | 编造编号 → 诚实拒答 |

## 4. 防幻觉观察

- 回答末尾的 `FABRICATE` 计数；
- 点击 `[卡N]` 跳转证据卡片；
- 编造编号问题应秒回拒答，不调用生成模型。
